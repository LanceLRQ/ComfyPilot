# 视频人物替换模块

首发配方为 [H3 单人视频替换](h3/README.md)，ID 为 `minimax-h3-replacement`。它包含固定 API 图、画布、官方模板原件、核心节点版本、四个模型的来源/哈希和安装回退说明。默认一张人物参考图与一段视频，768×448、124 帧、24 fps、20 步。

Agent 应将项目配方、API 图、画布原件与安装说明存放到当前项目的资源目录，再显式刷新。平台只读取内容，不导入节点代码，不自动安装依赖。

当前已支持声明校验与目标标准预检；媒体上传、真实提交和收片按后续任务实现。预检通过不表示模型文件、运行环境或画面质量已经验收。
