# 项目备份、恢复与移动

由本机 Agent 使用 export_project（需连接引用、destination 绝对路径）在线导出，或运行：

```sh
comfypilot export --project-root /absolute/project --destination /absolute/backup-new
comfypilot restore --project-root /absolute/restored-new --bundle-path /absolute/backup-new
```

MCP restore_project 使用 project_root 指定新项目目录、bundle_path 指定备份；不需要连接已有服务。目的目录必须尚不存在、父目录已存在；不覆盖项目、不在备份内部恢复。LAN 不能导出或恢复。导出响应不是媒体内容，备份保存在平台所在机器；请自行复制整个备份目录。

## 备份内容与完整性

SQLite backup 取得同一事务视图，使用副本生成有效配置；必要的数据库迁移仅作用于备份副本。复制数据库引用的输入、输出、代理、截图及项目 workflows/custom_nodes/modules/skills 文件，保存文件大小和 SHA-256 清单。来源、资源快照、反馈、命令回执和采用关系保存在数据库；原始外部路径只是历史证据，不用于自动读取或重新生成。

平台秘密文件、隐藏环境文件、私钥、依赖/缓存目录、PID/runtime、锁、日志、暂存及半文件排除。未接纳的 YAML 草稿不替换有效配置；未完成媒体任务没有正式原件，仅保存其任务证据。平台不能识别用户自行嵌入资源源码/工作流文本中的秘密，导出前应由用户核对这些资源。

清单最后写入；中断保留 transfer.incomplete 标记和现场，目录不能启动。失败后使用新的目录重新导出或恢复，不把半备份当项目。完整备份也不能直接 start，须 restore。磁盘故障发生在复制后时，保留现场且不给出成功回执。

恢复前检查固定相对路径白名单、重复/额外文件、符号链接、大小/哈希、SQLite integrity_check、foreign_key_check、项目身份、资源内容哈希、素材/版本来源引用及媒体完整性。复制后再次核对哈希。缺失、损坏或越界时停止，保留原件，不从日志猜测重建。

## 恢复后的状态

每次恢复产生新 UUID、回环监听、禁用所有执行端、清空运行进程/指标/预检以及远端副本所有权，手动派发暂停。采用、反馈、来源与历史回执可读；旧方案停止，任务无有效方案，旧在途 Run 归档为 cancelled，旧媒体任务变 blocked。不会对旧意图进行网络对账、恢复收片或重新 POST /prompt。

清理历史仍是原项目证据；旧远端台账不属于新 UUID。需要继续创作时让 Agent 重新检查工具与目标，明确启用目标并创建新的有效方案；不得通过恢复重置原授权额度。恢复提示缺少 FFmpeg/ffprobe 时，历史元数据仍可查，处理素材前先安装工具并加入平台 PATH。

## 原项目移动与故障

原目录移动须先 stop，连同完整目录移动后再按新绝对目录 start。UUID 不变，数据库根路径更新；旧运行记录归档为 runtime.moved.<随机UUID>.json，不接管旧进程。原记录中的进程仍存活时拒绝重新绑定，先停止原项目。MCP 旧连接根/实例均失效，须显式重新连接。

SQLite 仅支持已识别的本机文件系统，网络盘明确拒绝；空间不足需释放空间或完整移动项目。数据库损坏请停止平台、保留原目录及日志，使用完整备份恢复到新目录；不要删除库后让 Agent 从日志继续派发。较新数据库不能用较旧程序直接启动，升级/回退见安装说明。
