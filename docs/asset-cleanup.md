# ComfyUI 素材维护

仅处理用户指定执行端中、本项目已经登记的受管输入/输出副本。不会扫描模型、节点、未知目录或其他项目，不删除项目内正式素材、作品、代理、反馈及采用记录。未登记的上传半文件也不接管。

## 盘点与预览

本机维护页选择执行端，可盘点素材或填写范围说明后保存清理预览。MCP 使用 inspect_storage / prepare_cleanup，显式 project_root、connection_ref、target_id；可用 replica_ids 和 roles 缩小清单。prepare_cleanup 还需 user_instruction。两者均不删除文件；保存预览只写本项目元数据。

清单携带固定项目、目标快照、资产身份、原指纹、大小、业务引用修订、引用对象及保护原因；estimated_bytes 只累计当时符合条件的项。目标配置变更后不会把原清单套到新地址。仅有标准 HTTP 的执行端不能承诺物理清理能力。

活动 Run、待核对、草稿/有效方案使用的输入、未收片输出、待审版本、未确认反馈、未知引用都受到保护。待审输出即使有本地副本也不清理。已审阅输出还需本地技术检查通过的原件且哈希匹配；不再使用的输入还需项目原始副本可读且匹配。未知或变化的状态不能当作安全。

当前接口提供只读盘点和持久清理预览；物理删除在 M4/4.2 接入。预览中的“可清理”不是执行许可，用户指示范围和执行前复核仍须满足。
