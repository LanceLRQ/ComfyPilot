# ComfyUI 素材维护

仅处理用户指定执行端中、本项目已经登记的受管输入/输出副本。不会扫描模型、节点、未知目录或其他项目，不删除项目内正式素材、作品、代理、反馈及采用记录。未登记的上传半文件也不接管。

## 盘点与预览

本机维护页选择执行端，可盘点素材或填写范围说明后保存清理预览。MCP 使用 inspect_storage / prepare_cleanup，显式 project_root、connection_ref、target_id；可用 replica_ids 和 roles 缩小清单。prepare_cleanup 还需 user_instruction。两者均不删除文件；保存预览只写本项目元数据。

清单携带固定项目、目标快照、资产身份、原指纹、大小、业务引用修订、引用对象及保护原因；estimated_bytes 只累计当时符合条件的项。目标配置变更后不会把原清单套到新地址。仅有标准 HTTP 的执行端不能承诺物理清理能力。

活动 Run、待核对、草稿/有效方案使用的输入、未收片输出、待审版本、未确认反馈、未知引用都受到保护。待审输出即使有本地副本也不清理。已审阅输出还需本地技术检查通过的原件且哈希匹配；不再使用的输入还需项目原始副本可读且匹配。未知或变化的状态不能当作安全。

## 执行与重试

用户明确指定范围后，在本机维护页保存预览，再点击“执行此清单”打开确认框。确认内容来自已保存清单：执行端名称/ID/地址、范围说明、可删除副本数量与预计字节、清单内保护数量，并可展开项目/清单/修订及固定文件明细。初始焦点为取消；核对并勾选确认后才能“确认删除副本”。取消、关闭、Esc 和离开项目视图均不发送删除请求，重新打开须重新勾选；项目状态断连时禁用确认。没有预计可删除副本时不开放执行。

MCP 调用 execute_cleanup，提供 plan_id 和唯一 command_id；list_cleanup 读取原清单和回执。网页确认仅增加操作核对，不修改 MCP 契约或服务端授权。清单范围固定，执行前再次核对目标、归属、原件哈希、文件指纹及当前引用。领取 deleting 期间，新增计划或相关副本引用被拒绝。

逐项结果为 deleted、already_missing、protected、changed、failed。相同 command_id 返回原回执；不确定是否执行成功时先重读原回执。失败后使用新命令 ID 重试同一 plan_id，仍逐项复核，不扩大范围。指纹不同的同名新文件会跳过，须重新盘点后由用户决定。

网页收到明确 failed 项后，“按原清单重试”也先打开确认框，确认后使用新命令 ID、同一 plan_id。若网络异常尚未取得回执，原执行入口的确认框会说明复用原 command_id 核对回执；不因连接丢失创建新的清单或自动扩大删除。修改执行端、勾选或范围说明继续使旧预览失效，必须重新保存后执行。预计字节不是保证释放的磁盘空间。

物理清理直接 unlink。deleted_bytes 是已删除文件大小之和的估算；逐项 free_change_bytes 是可获得的磁盘空闲变化，会受其他磁盘活动影响，不等同于该文件独占释放量。无原件、待审和反馈未确认的副本继续保护；本地作品及采用/反馈记录保留。

本机模式需要配置可访问的 input/output 绝对目录。远端模式需要素材桥接 capabilities.features 包含 delete；旧扩展须空闲时升级并按既有方式重启 ComfyUI。仅标准 HTTP 或旧桥接返回明确不可清理原因，不自动转用 SSH。远端受限删除只接受台账中本项目的固定路径与指纹，串行协调同一素材的上传、读取和删除。
