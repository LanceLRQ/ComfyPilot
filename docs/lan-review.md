# 局域网审片

默认只监听 127.0.0.1。需要同一受信任局域网的设备审片时，让本机 Agent 更新项目配置的 server 字段，接纳配置后停止再启动：

```yaml
server:
  host: 0.0.0.0
  port: 8765
  lan_hosts:
    - 192.168.1.20
```

将示例地址换成本机实际 IPv4 地址。lan_hosts 是 Host/Origin 白名单，须填写实际接口地址；不接受任意域名或通配符。监听和白名单改变需重启。其他设备访问 `http://192.168.1.20:8765`；本机 Agent/MCP 继续访问回环。停止后改回 host=127.0.0.1 再启动即可关闭 LAN。

不设账号或平台密钥；能访问该受信任网络和端口的设备可看作品、原片，提交反馈、截图及采用/拒绝。请按用户要求开放网络，不将它当作公网服务或通过反向代理转发远端请求到本机回环。TCP 回环是本机控制边界，平台关闭代理头信任；不支持用代理头替代真实连接来源。

远端可读取脱敏生产状态、版本与事件，播放/下载受管媒体，保存反馈及用户决定。配置、资源、执行证据、Agent 上下文、任意本地路径导入、收片恢复、调度、清理和后续备份恢复入口限本机连接。远端页面隐藏这些管理入口；服务端独立拒绝调用，修改 source、Host 或 X-Forwarded-For 不能授权管理操作。远端反馈来源由服务端写为 web_user，不能标记 Agent addressed。

每个请求检查 Host；带 Origin 的请求必须与实际 Host 同源。写入还需当前实例 ID；它用于防止向旧实例误写，不是登录密钥。远端快照只包含审片所需字段，移除目标 URL、配置、图参数、原始证据、本地路径和 PID；指标保留值、采集/过期时间，来源显示通用说明。用户文本通过 React 文本渲染；受管路径校验与媒体 Range 继续生效。

手机专注布局、候选缩略图和反馈时间轴复用相同审片数据；素材和版本 poster 属于只读审片白名单，仍只能按登记 ID 读取。增加预览不扩大 LAN 的管理、完整执行证据或路径访问权限。此次响应式浏览器验证不等同第二台实体手机验收。

验证范围：macOS 安装版显式 LAN，第二台 Linux 设备实际读取脱敏状态、保存合成样片反馈/采用、206 媒体访问、伪造 Host/代理头管理请求拒绝。浏览器用 LAN 地址验证审片页面和播放器。该验证不补齐 Claude Code/Codex 的双宿主完整矩阵，也不代表公网或多用户认证验收。

M4 联合回归补测了 HTTP LAN 浏览器实际输入批注和采用/拒绝。命令 UUID 使用 getRandomValues 生成，兼容没有 crypto.randomUUID 的普通 HTTP 地址；不要求为此启用 HTTPS。业务到达时延、播放与草稿保持及剩余条件见 [M4 验收](m4-validation.md)。
